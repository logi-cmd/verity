Verity 不执行 README 片段，也不推测项目本应做什么。每个阶段都绑定已提交的声明、实际环境和以后仍能解释的观察结果。

01

检测可执行目标

锁文件、清单、脚本、框架入口和已提交测试配置共同生成有界计划。命令存在歧义就停止。

02

执行隔离快照

运行前记录仓库指纹。逃逸符号链接或源仓库变化会使验证失效，不会被悄悄接受。

03

要求机器 Oracle

声明的测试、健康检查、浏览器行为或仓库内冒烟自动化必须通过。仅有进程和端口仍是未验证。

04

签名有界结果

通过的凭证用本机 Ed25519 签名绑定快照和环境。复验结果无需暴露日志或源代码。
