VVerity

PRIVACY

Local by design.

Verity does not require an account and contains no telemetry or cloud-upload transport. Repository snapshots, plans, logs, paths, command output, and complete receipts stay on the current machine. Secret values use the operating-system credential store and are excluded from logs and receipts. A diagnostic report contains allowlisted environment metadata only and is saved locally when you explicitly export it.
