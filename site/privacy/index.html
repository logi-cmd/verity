Verity / Privacy

Your project data stays on your machine

Verity contains no telemetry or upload transport. Repository snapshots, plans, logs, paths, command output, and complete receipts stay on the current machine.

Data handling

Secret values use the operating-system credential store and are excluded from logs and receipts. A diagnostic report contains allowlisted environment metadata only and is saved locally when you explicitly preview and export it.

The public website does not load analytics, advertising pixels, or third-party tracking scripts.
