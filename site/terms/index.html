Verity is provided under MPL-2.0 without warranty. It is intended for repositories whose source you trust.

Meaning of a result

A local receipt records observations for one snapshot, host, environment, and time. It is not security certification, remote attestation, or a guarantee that the software is correct.

You remain responsible for deciding whether to execute a repository and for reviewing patches before writing them back.
