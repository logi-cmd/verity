## Regression Fixed

`agent_probe_timeout` was a false timeout. The child process could emit more data than the Windows pipe buffer while Verity waited for exit before reading stdout and stderr. The child then blocked on pipe backpressure until the 90 second deadline. Verity now drains both streams concurrently, and a regression test writes 200,000 bytes through the same wait path.

The Codex probe also now passes `--skip-git-repo-check` because its isolated capability workspace is intentionally not a Git repository. Claude bare mode now performs an immediate credential preflight.
