# Release status

Current status: **pre-public beta**.

Implemented in this workspace: versioned core contracts; deterministic targets for Node, Deno, Bun, static web, Rust, Python, Go, Godot, Compose, Java/Kotlin, C/C++, .NET, PHP, and Ruby; target-specific container/native environment checks; CLI commands; snapshot fingerprinting; phase supervision; Web HTTP/DOM and declared build/test/package oracles; signed local receipts; single-task desktop UI; history; Docker Desktop capability diagnostics and user-triggered startup; Windows CLI/MSIX Agent discovery; explicit Agent capability certification; stack-specific cleanup analyzer status and candidates; isolated candidate-patch verification; verified diff review with hash-guarded write-back; one-shot Agent task handoff; and user-reviewed local diagnostic export.

Not yet a public claim: three-platform signed installers, the required five-real-project-per-adapter matrix, the 15-project public-beta matrix, the 75-project 1.0 matrix, any Agent version that has not passed the in-app capability test on that installation, full native desktop/game automation, Podman support, or remote telemetry. Hosted execution, cloud upload, accounts, and payment are outside this release. New adapters have deterministic fixture coverage, but their public support claim remains gated on the real-project/platform matrix. Website download controls remain unavailable until a platform has a signed artifact and its acceptance matrix has passed.
