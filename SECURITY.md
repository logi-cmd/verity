# Security policy

## Supported versions

Only the latest beta release receives security fixes while Verity is pre-1.0.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for `logi-cmd/verity`. Do not open a public issue containing an exploit, private repository content, receipt, path, log, command output, token, or signing material.

Verity runs commands found in repositories. Only use it with source you trust. Isolation reduces accidental host impact; it is not a malicious-code security boundary. A local receipt is tamper-evident for the installation that signed it, not remote attestation or a security certification.
